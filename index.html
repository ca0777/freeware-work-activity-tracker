Questions

Frequently asked questions.

Is Work Activity Tracker really free?

Yes. It's a freeware work activity tracker app — free to download and use, with no license fee, no ads, and no premium tier to upsell you into.

Does this work activity tracker software log my keystrokes or take screenshots?

No. It only checks whether the mouse or keyboard has moved recently, using the same signal Windows itself uses to detect idle time. It never records which keys you press, never captures screen content, and never uploads anything.

Where is my data stored?

Locally, in a folder next to the app itself — as plain JSON files and daily .xlsx exports. None of your tracked data is ever sent anywhere.

Does the app connect to the internet?

Only for one optional thing: checking GitHub's public releases page to see whether a newer version exists. That request carries none of your data, and you can switch it off with the "Check for updates" checkbox.

Does "Keep PC awake" fake activity?

No. It only asks Windows not to sleep or turn the screen off while it's ticked. It creates no mouse or keyboard input, so your active and idle time stays accurate, and it can't override a screen lock your organisation enforces by policy.

What counts as idle time?

You set a grace period, called the idle threshold (5 minutes by default). Any stretch without mouse or keyboard input shorter than that still counts as active; only time beyond the threshold counts as idle.

Does it work for night shifts or late sessions?

Yes. Its workday runs 6 AM to 5:59 AM the next calendar day, so working past midnight still logs under the day you started, instead of splitting across two dates.

What Windows versions does it support?

Windows 10 and Windows 11, 64-bit. It ships as a single .exe with no installer and no dependencies to set up.
